# ClipShot branding assets

The supplied master artwork lives here:

- `clipshot-icon.svg` — editable source logo.
- `clipshot-icon.png` — raster version used in the dashboard.
- `clipshot.ico` — Windows application and window icon, exported with multiple icon sizes.

When the logo changes, update the PNG and ICO exports from the SVG and keep all three files in sync. The WPF app uses the ICO for its executable/window icon and the PNG for the dashboard header.
