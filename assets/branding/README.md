# ClipShot branding assets

This is the central home for ClipShot's brand artwork.

- Upload the master vector icon here as `clipshot-icon.svg`.
- Recommended artwork: square canvas, transparent background, and `viewBox="0 0 256 256"`.
- Windows executable and taskbar icons require a Windows `.ico` asset. WPF cannot use SVG directly as the application icon, so the SVG should remain the editable source artwork and be converted into the Windows icon sizes during the branding integration.
- Keep exported previews here only when they are useful for documentation.

The actual icon artwork has not been added yet. Add `clipshot-icon.svg` to this folder when it is ready.
